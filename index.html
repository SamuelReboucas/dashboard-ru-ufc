PROJETO DE DADOS · NUTRIÇÃO INSTITUCIONAL

Um indicador de desperdício mostrava 1.957%.

Fisicamente impossível — e quase passou despercebido. Este projeto trata, modela e apresenta os dados de produção, satisfação e temperatura do RU/UFC, com cada fórmula validada contra a base real antes de virar número na tela.

Ver o dashboard ao vivo Como foi construído
O QUE ESTAVA POR TRÁS DO 1.957%

Uma coluna de "sobra limpa" chegava em branco — não zero, em branco — em 98,5% das linhas de uma das unidades. Vazio menos alguma coisa vira vazio; a soma agregada descartava essas linhas do denominador enquanto o numerador continuava contando normalmente. Corrigido: tratar ausência como zero, não como desconhecido. O indicador caiu para 22,6% — alto, mas real.
